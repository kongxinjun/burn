# Burn Inference Tests

End-to-end inference tests on complete models, run on the backend selected by the alias.

| Test | Failure it catches |
| --- | --- |
| `*_matches_pytorch` | Imported weights or composed layers produce different outputs from PyTorch |
| `padding_does_not_change_real_tokens` | Padding a batch changes the results of its real tokens |
| `batching_does_not_change_outputs` | A sample's output depends on the batch it is in |
| `accelerated_device_matches_flex` | A GPU or fused backend disagrees with the Flex CPU backend |
| `repeated_inference_is_stable` | Fusion caches or autotuning change results across requests and shapes |
| `concurrent_inference_matches_sequential` | Threads sharing a model interfere with each other |
| `cached_decoding_matches_full_decoding` | Autoregressive caching diverges from a full forward pass |

Run from this directory:

```sh
cargo test-flex
cargo test-metal
cargo test-metal-no-fusion
cargo test-metal concurrent   # Only the tests whose name contains the filter
```

`fixtures/reference.json` and the weights next to it are generated by
`uv run fixtures/generate.py`. The script defines the PyTorch models independently of Burn.

On macOS the runner leaves through `_exit`, because CubeCL's exit handler aborts the process there
after the tests have finished.
